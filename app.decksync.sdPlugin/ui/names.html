Fetching decks…

The deck name is shown on the page dial ("Deck1 - Edit") and on the Target key. Names are shared by all page dials and Target keys. Empty = the device's own name.
Page names come from the Stream Deck app: name the pages of the DeckSync profiles there, and the dial, the page markers and Go to page pick them up.

Colours are hex codes, e.g. #FF8800, and apply to every DeckSync key and the dial strip. The accent lights the frame when the decks are in sync. Empty = default.
