"This page" is the page this marker sits on (1 = first page). The DeckSync profiles come with one marker on every page.
The key shows the page's name from the Stream Deck app, with "p3" underneath. Name the page in the app and the marker follows.
"Others go to page" maps pages freely, e.g. page 2 here sends the other decks to page 4. Empty = same number.
Press the marker to force a resync.
